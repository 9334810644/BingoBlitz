# 🎯 Online Multiplayer Bingo

A fun and interactive **online multiplayer Bingo game** designed to let friends play together remotely using a simple **room-code system**. Create a private game room, share the room code with your friends, join the same room, and enjoy a real-time Bingo match together.

## ✨ Features

* 🎮 **Multiplayer Gameplay** – Play Bingo with friends online in the same room.
* 🔐 **Room Code System** – Create a room and share a unique code with your friends.
* 👥 **Private Rooms** – Only players with the room code can join your game.
* ⚡ **Real-Time Interaction** – Game actions and player updates are synchronized between connected players.
* 🎲 **Automatic Number Generation** – Numbers are generated and called during the game.
* 🏆 **Win Detection** – Automatically detects completed Bingo patterns and determines the winner.
* 📱 **Responsive Interface** – Designed to work smoothly across desktop and mobile devices.
* 🎨 **Clean & Interactive UI** – Simple controls and visual feedback make the game easy to understand and fun to play.
* 🚪 **Easy Join System** – Players can quickly join an existing game using the room code.
* 🔄 **Replayable Matches** – Start new rounds and keep playing with the same group of friends.

## 🕹️ How to Play

1. Create a new game room.
2. Share the generated **room code** with your friends.
3. Friends enter the code to join your room.
4. Start the Bingo game once everyone is ready.
5. Numbers are called automatically during the game.
6. Mark the matching numbers on your Bingo board.
7. Complete the required Bingo pattern.
8. Claim your Bingo and let the game determine the winner. 🏆

## 💡 Project Goal

The project was created to make the classic Bingo experience more social by allowing friends to play together even when they are in different locations. The room-code approach keeps joining a game simple while providing a private space for each group of players.

## 🚀 Future Improvements

Possible future additions include player profiles, chat, custom Bingo rules, different game modes, sound effects, animations, leaderboards, spectator mode, game history, and improved matchmaking.

This project is built as a fun multiplayer experiment and can be further extended into a complete online gaming platform.
