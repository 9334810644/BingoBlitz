# BingoBlitz

This contains everything you need to run BingoBlitz locally.

View your app in AI Studio: https://ai.studio/apps/7c4416e4-75ec-43ff-9663-7a7e6f3e299a

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
